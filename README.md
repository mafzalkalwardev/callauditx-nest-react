## Project Showcase

**CallAuditX** — full-stack call auditing platform with NestJS backend, React frontend, JWT auth, and PostgreSQL via Prisma.

## Quick Start

```bash
# Backend
cd backend
cp .env.example .env
npm install
npm run start:dev

# Frontend
cd frontend
npm install
npm run dev
```
